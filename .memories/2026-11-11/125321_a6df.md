## POC merged on main (b06a73b)

- **What:** 4 Sonnet 5.5 delegates built sources, db, player and worker+UI. Everything is merged: 63 tests pass, clippy -D warnings is clean, 5.8k lines, largest file 268 lines.
- **Verified:** the app launches (glow) with a scratch HOME and creates `~/Library/Application Support/dev.iptv-player.IPTV-Player/iptv.db`. The UI agent imported iptv-org news.m3u (1057 streams, 13 categories). 200k-stream import takes 0.55s in release.
