## IMDb + Trakt API research (plan stage, nothing implemented)

**IMDb** (no free official API; official = AWS Data Exchange, paid):
- Search: `GET https://v3.sg.media-imdb.com/suggestion/<first letter>/<query>.json`. No auth needed. Returns `d[]` with `id` (tt…), `l` title, `y` year, `qid` (movie/tvSeries/tvMiniSeries…), `i.imageUrl` poster, `s` cast.
- Details: `POST https://caching.graphql.imdb.com/` with header `x-imdb-client-name: imdb-web-next` (403 without it). Fields verified: titleText, titleType{id}, releaseYear{year endYear}, ratingsSummary{aggregateRating voteCount}, plot{plotText{plainText}}, primaryImage{url}, runtime{seconds}, genres{genres{text}}, certificate{rating}, principalCredits{category{id} credits(limit:3){name{nameText{text}}}}, episodes{seasons{number}}. Its disclaimer says personal, non-commercial use only.
- www.imdb.com title pages return 202 (WAF challenge), so they can't be scraped. The imdbapi.dev domain no longer resolves.

**Trakt** (OpenAPI at https://developer.trakt.tv/openapi.json):
- Device flow: POST /oauth/device/code and /oauth/device/token need only `client_id`; `client_secret` is deprecated. Access token lasts 7 days. Refresh tokens are single-use, and `invalid_grant` means the user must re-auth.
- Rate limits: authed POST/PUT/DELETE 1/s; GET 500 per 5 min; 429 responses come with Retry-After.
- Scrobble start/pause/stop: stop at ≥80% records a play; 1–79% saves playback (pause); <1% returns 422; a duplicate returns 409.
- Sync endpoints: last_activities, watched/{type}, playback, history add/remove. /search/{id_type}/{id} looks up imdb/tmdb ids with client_id only.
- Free (non-VIP) account limits cover only lists, watchlist and favorites. History, scrobble and playback are unlimited.
- extended=images exists.

**Codebase facts**:
- Details come from Xtream `get_vod_info` (`sources/xtream/info.rs` → `MediaInfo`).
- Progress lives in the `history` table (position_s/duration_s; episodes keyed `ep:<id>`).
- Only the embedded player reports positions (`Command::SavePosition`).
- Xtream `extra_json` keeps only rating/added/plot/backdrop_path, so any provider `tmdb` id is dropped today.
