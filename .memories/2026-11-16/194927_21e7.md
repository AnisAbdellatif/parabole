## EPG (XMLTV) v1 landed on main (not pushed)

**WHAT:** commits 0c066a5 (model `Programme`/`NowNext`), e5aada1 (`src/epg/` fetch+gzip sniff+quick-xml streaming parse, `Window::around`), aed03bc (`migration_9`: `epg_programmes`, `sources.epg_refreshed_at`, view `stream_epg`), 14db532 (bad attr skips programme), d57041c (`sources/guide.rs` guide_urls, Xtream `xmltv.php` fallback, `worker/epg.rs` serialized queue), c4448cd (UI: now-line + airing progress on live rows, `epg-guide.slint` panel via RowAction::Info on live rows, player top `epg-now`, 60 s timer).

**Design rules (keep):**
- All stream→guide matching goes through SQL view `stream_epg`; name-fallback / manual links = redefine view only.
- `epg/` is pure (no DB/UI); worker fetches off-thread, writes on worker thread in one short transaction (avoids 5 s busy_timeout).
- One guide job at a time; triggers: after playlist refresh, and AutoRefresh for guides >12h old.

**Evidence:** real provider: 98,877 programmes / 2,894 channels stored; 6,084 of 56,553 live streams have a programme airing now (8,258 have epg_id). fmt/clippy/tests clean.

**Unverified:** UI never visually checked — screencapture -l of the Slint window returned byte-identical images across 3 launches; startup also ignores persisted `sel` Category (always first category).
