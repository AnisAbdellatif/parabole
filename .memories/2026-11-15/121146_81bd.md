## Slint experiment: phase 1 done, phase 2 running (3 parallel areas)

**Phase 1** (`exp/slint-ui`, 2993ff8):
- The main window works: sidebar, lazy `StreamModel` list, off-thread logo loading via `imgcache::get_or_fetch`, worker bridge using `invoke_from_event_loop`, toasts.
- All state sits behind `thread_local APP` + `with_app` (`try_borrow_mut`, so it is not re-entrant).
- The native Agent `sonnet` alias routed to Antigravity and hit 429 twice. I switched to `delegate_task` on omniroute `claude/claude-sonnet-5-5` (Anthropic direct), which worked.

**Scaffold** (f57f4c0), designed by me per the user's rule "orchestrator designs, subagents implement":
- Per-area globals `PlayerApi`, `BrowseApi`, `DialogApi`, each with a `key(KeyEvent) -> bool` callback.
- Host files: `player-pane`, `browse-host`, `dialog-host`.
- `src/slint_ui/{player,browse,dialogs}/mod.rs`, each with an `Area` struct, `connect` and `on_event` returning `Option<Event>`.
- Event chain: dialogs → player → browse → core. Key chain: Dialog → Player → Browse → core.
- Full spec in `docs/slint-phase2.md`, including file ownership.

**Phase 2 delegates** (worktree isolation; each runs `git checkout -B exp/slint-<area> exp/slint-ui`):
- **A, player** (effort high): `MpvCore` split with `Deref` for egui; GL via `set_rendering_notifier` + `BorrowedOpenGLTextureBuilder`; save/restore the FBO binding.
- **B, browse:** sort, chips, menus, edit mode, poster grid, series/details, empty states, arboard (already in Cargo.lock).
- **C, dialogs:** sources, settings, profiles, group.
