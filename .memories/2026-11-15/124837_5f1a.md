## Slint experiment complete on `exp/slint-ui` (9686f8e)

**What landed:**
- The player, browse and dialogs areas are merged.
- `src/slint_ui/wiring.rs` connects `BrowseApi.request-dialog` to `DialogApi.open-dialog`, copying the group context across. The duplicate group save in browse was dropped.
- The comparison table is in `docs/slint-experiment.md`.

**Measurements** (real DB copy, 290k streams):

| | egui | Slint |
|---|---|---|
| UI lines | 6.7k | 7.25k (4.6k Rust + 2.7k `.slint`) |
| Clean release build | 83 s | 145 s |
| Incremental build | 1 s | 3–4 s |
| Crates | 350 | 497 |
| Stripped binary | 20.8 MB | 23.8 MB |
| RSS | 155 MB | 134 MB |
| Idle CPU | ~0 | small (toast timer) |

**Findings:**
- Slint shapes Arabic RTL correctly; egui reverses word order (no bidi).
- Slint shows tofu for superscript letters because DejaVu isn't registered.
- Embedded mpv works in Slint via `set_rendering_notifier` + `BorrowedOpenGLTextureBuilder` (`flip_y=false` + `BottomLeft` origin).
- `MpvCore` is split out of `EmbeddedPlayer` (`Deref`), so both UIs share it.

**Process lessons:**
- The native Agent `sonnet` alias routed to Antigravity and hit 429 twice. `delegate_task` with omniroute `claude/claude-sonnet-5-5` works.
- An orchestrator-written spec, a scaffold with per-area ownership, and parallel agents merged with only trivial union conflicts.
