## Slint Ambient redesign merged, headless UI tests in place

- **What:** `exp/slint-ui` (head 60a4255) now has all four Ambient parts (S1 shell/theme, S2a player, S2b hero/posters, S2c palette/appearance), plus three follow-ups: vcenter sweep, headless tests, polish pass.
- **Headless tests:**
  - `tests/slint_behaviour.rs` uses `i-slint-backend-testing` (=1.18.1, ElementHandle).
  - `tests/slint_snapshots.rs` uses a custom software-renderer Platform.
  - Goldens live in `tests/fixtures/slint-snapshots/`; set `UPDATE_SNAPSHOTS=1` to regenerate.
  - No window is ever opened.
- **Key learnings:**
  - Slint HorizontalLayout defaults to cross-axis stretch, so fixed-height children sit at the top. Use `cross-axis-alignment: center`.
  - A `.slint` font import doesn't join the fallback chain. Use `fonts.rs` with `unstable-fontique-011`.
  - The worker's osascript input hit the user's Brave window, so workers now get screenshots plus env hooks only.
- **Decisions:**
  - Zap neighbours show only in fullscreen; docked and mini show the current card.
  - Dialog bodies get a scroll thumb when they overflow.
- **Impact:** the snapshot tests caught 5 real UI bugs that manual screenshots missed.
